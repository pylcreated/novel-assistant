# Roadmap

## 当前阶段：v0.4 稳定性与兼容性
目标：在不重构架构的前提下，保证“可持续迭代 + 数据安全”。

### 优先级 P0
- 完成全链路回归测试并沉淀测试记录
- 收敛高风险保存链路问题（保存失败、500、兼容字段类型错配）
- 提升项目数据损坏后的恢复可操作性（备份可追溯）

### 优先级 P1
- 收敛双字段并存风险（`plot_threads/plotlines`、`feedbacks/feedback_notes`）
- 增强错误提示分层（网络错误 / 接口错误 / 数据错误）
- 完善文档与实现一致性

---

## 下一阶段：v0.5（信息架构与体验优化）
目标：从“表单维护”升级为“创作工作台体验”。

- 优化项目页模块切换与阅读态
- 提升卡片化信息展示质量（人物档案 / 故事脉络 / 章节手稿）
- 减少编辑噪音，强化创作路径清晰度

---

## 中期阶段：v0.6（创作流程支持）
目标：强化创作过程管理，但不引入复杂平台能力。

- 章节推进状态的流程化表达
- 反馈到创作层的闭环追踪
- 更系统的版本与迁移说明

---

## 非目标（当前不做）
- 用户登录/权限系统
- 云端同步
- 多人协作
- 数据库替代本地 JSON
- 自动生成正文（AIGC 主写作）
