# 产品定位

## 一句话
Novel Assistant 是一个极简小说写作与档案管理工具：  
作者在同一个项目里写正文、管档案，不被复杂字段打断创作。

## 目标用户
- 长篇小说作者
- 连载作者
- 需要长期维护设定与伏笔的创作者

## 本版核心能力
1. 章节正文
- 新增章节
- 切换章节
- 编辑章节标题与正文
- 删除章节
- 本地保存并持久化

2. 创作档案
- 档案类型：人物 / 伏笔 / 情节线 / 其他
- 新增档案
- 编辑档案标题、类型与正文
- 删除档案
- 本地保存并持久化

## 产品边界
- 本地单机使用
- 不做账号系统
- 不做云同步与多人协作
- 不做 AI 自动正文生成
- 不做复杂流程状态管理

## 兼容策略
- 旧版七层字段在 JSON 中保留，避免历史数据丢失
- 新版前端主入口切换为“章节正文 + 创作档案”
