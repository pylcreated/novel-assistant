# Changelog

## v0.4 (Current)
- 建立 `schema_version` 机制（当前目标版本 `0.4`）
- 引入读取时迁移流程，提升旧项目兼容能力
- 人物 / 情节线 / 章节完成结构化编辑闭环
- 新增反馈结构化记录（`feedbacks`）
- 保留兼容字段（如 `plotlines`、`feedback_notes`）用于历史数据过渡
- 增强删除接口兼容：`DELETE` + `POST /delete` + `POST /remove`
- 保存与删除前执行本地备份（`data/backups/`）

## v0.3
- 引入人物、情节线、章节关联关系
- 增加结构关系展示与基础统计能力

## v0.2
- 人物、情节线、章节从大文本升级为结构化列表
- 前端支持新增、编辑、删除结构化条目

## v0.1
- FastAPI + 本地 JSON 最小可用版本
- 支持项目创建、读取、更新
- 支持基础七层内容录入与保存
