# v0.1 范围定义（历史文档）

> 本文档仅保留 v0.1 的历史范围，用于回溯，不代表当前版本全部能力。

## v0.1 做什么
1. 项目列表展示
2. 项目创建
3. 项目详情查看
4. 七层内容基础编辑
5. 本地 JSON 持久化
6. 基础 API（健康检查、创建、查询、更新）

## v0.1 不做什么
1. 用户系统与权限
2. 数据库
3. 云端同步
4. 多人协作
5. AI 自动生成正文
6. 复杂关系图
7. 小程序或 App

## v0.1 完成标准
1. 后端可启动并通过健康检查
2. 可创建并读取项目
3. 可更新项目并写入 `data/projects/`
4. 前端可完成创建、编辑、保存、刷新后读取

## 说明
- 后续迭代能力请以 `README.md` 与 `docs/data_model.md` 为准。
